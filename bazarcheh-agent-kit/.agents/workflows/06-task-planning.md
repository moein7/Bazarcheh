# Workflow: Task Planning

For each task:
- Give a stable ID.
- State one outcome.
- Link requirement IDs.
- Define included and excluded scope.
- Name dependencies.
- Assign one primary owner.
- Define owned files/modules.
- Define acceptance criteria in observable terms.
- Define commands/tests.
- Identify risks and ADRs.
- Estimate time proportionate to challenge budget.

Split tasks when they have independent owners or acceptance criteria. Do not split into tiny tasks that create more overhead than value.
