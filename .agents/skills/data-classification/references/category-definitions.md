# Category Definitions

- delivery: shipping, dispatch, tracking, late/missing/delivered-not-received parcel.
- payment: payment attempt, charge, duplicate charge, transaction, checkout payment.
- refund: request/status/problem about returning money or refund processing.
- product_quality: damaged, defective, unsafe, counterfeit/quality concern about item.
- account: login, access, identity, profile, account security.
- other: anything not best represented by the above.

These descriptions are working guidance, not a substitute for primary-intent analysis. When a message touches multiple topics, classify what the customer is actually asking support to do.
