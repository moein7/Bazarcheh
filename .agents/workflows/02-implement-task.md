# Workflow: Implement a Task

1. Read `AGENTS.md`, the task definition, relevant requirements, ADRs, and skill.
2. Confirm dependencies and file ownership.
3. Inspect current code before editing.
4. State a short implementation plan and files expected to change.
5. Implement only the task scope.
6. Add or update tests alongside code.
7. Run focused tests, then relevant regression tests.
8. Review diff for unrelated changes, contract regressions, unsafe behavior, and secrets.
9. Update docs/ADR/task board as needed.
10. Submit the task completion report.

If a requirement is ambiguous or an accepted ADR conflicts with the task, stop and ask the orchestrator. Do not silently choose.
