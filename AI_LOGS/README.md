# AI-assisted engineering logs

- `IMPLEMENTATION_SESSION.md` contains the factual implementation history for the supplied project. It is not a verbatim model transcript.
- `2026-11-13_GOV-001.md` records the agent-governance and documentation preparation task.

Every future implementation task must append a dated `<date>_<TASK-ID>.md` record using `docs/agent-governance/CHANGE_CONTROL_AND_LOGGING.md`. Logs must not contain customer message bodies, secrets, raw prompts or full model responses. Do not claim external agent transcripts unless exported from the actual tool.
