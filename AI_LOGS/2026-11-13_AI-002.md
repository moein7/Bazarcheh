# AI-002 — Multilingual and resilient AI reply generation

- **Date:** 2026-11-13
- **Status:** Review (backend regression tests passed; frontend runtime/build not verified)
- **Scope:** Mixed-script language detection, model failure fallback, browser offline fallback, timeout bounds, activity outcome logging and documentation.

## Changes

- `backend/app/drafts.py`: dominant-script language heuristic; generic safe Persian/English fallback; AI errors, unavailable provider, empty/unsafe response and language mismatch now return editable fallback instead of blank blocked response.
- `backend/app/llm.py`: bounded 5-second connection timeout; request timeout remains configurable.
- `backend/app/config.py`, `.env.example`, `docker-compose.yml`: default `LLM_TIMEOUT_SECONDS` reduced to 35 seconds.
- `backend/app/api.py`: records `draft_fallback` vs `draft_generated` outcomes and source metadata.
- `frontend/src/api.ts`: local generic fallback helper for API/network failure.
- `frontend/src/components/AttentionList.tsx`, `MessagesTable.tsx`: display fallback text as editable/copyable while retaining warning.
- `frontend/src/types.ts`, `ActivityLog.tsx`: source metadata and fallback log label.
- Updated `AGENTS.md`, `docs/AI_REPLY_WORKSPACE.md`, local Ollama/config docs, README, task board and changelog.

## Safety notes

- Fallback is generic, makes no refund/payment/date/timeline commitments, is editable, and is not sent automatically.
- Model output that fails safety or language checks is discarded rather than shown.
- Activity metadata stores outcome/source/warnings only, not customer message content or raw prompts.
