# UX-002 — Integrated dashboard behavior and multilingual AI

## Implemented
- Header shows live Tehran time as HH:MM beside the Persian date; one-second refresh remains active.
- All Messages renders all matching rows (not only the first 500), with a per-row reply action.
- AI system prompt now asks for language identification and a response in the customer's own language across model-supported languages; Finglish remains Persian.
- Removed binary-language output mismatch rejection and allowed `auto` as the language key for multilingual style feedback. Persian/Finglish remain explicitly tagged `fa`.
- Overview category selection now uses latest-selection-wins behavior.
- Retained manual-response workflow, editable fallback, activity logs, safety restrictions and no automatic sending.

## Limitation
Multilingual output depends on the configured Ollama model's language capability. Offline fallback templates are currently Persian and English; operators can replace them manually.
