# UX-001 — Manual operator replies

## Change
Added an explicit manual-reply path to both reply surfaces. Operators can discard AI/fallback text and author a fresh response in the same editor.

## Safety and privacy
Manual reply content is sent only to the existing feedback endpoint after the operator clicks copy, where it is sanitized before being saved as a style example. Activity metadata stores only source/language/edit state, never the reply body. No message is sent to the customer.

## Verification
Backend regression tests cover manual feedback classification and content-free clear-event logging. Backend suite: 42 passed. Frontend syntax check: 14 TS/TSX files, zero syntax errors. Full frontend build/Vitest/browser verification remains pending because frontend dependencies are not installed in this environment.
